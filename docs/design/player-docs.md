# Документация для игроков — план

Живой документ, как остальные в `docs/design/`. Решения — по мере обсуждения.

## Как читать

- ✅ **решено** — договорились, можно делать.
- 🔲 **открыто** — нужно решение владельца.
- 💡 **идея** — можно сделать, решить, нужно ли.

## Часть 0 — правила

✅ **0.1. Писать руками огромные rich-посты не нужно.** Документация — Markdown-файлы
в `docs/players/`, бот сам превращает их в посты. Rich-сообщения Telegram понимают почти
обычный Markdown (заголовки, списки, таблицы, цитаты, код, `<details>`, сноски, картинки);
лимит — 32 768 символов и 500 блоков на сообщение, раздел целиком влезает в один пост.

✅ **0.2. Гибрид: канал + мини-справка в боте.**
- Полная документация — чистый канал: прод `@chestor_docs` (бот `@chestor_chat_bot`),
  стенд `@chestor_docs_test` (бот `@true_hax0r_bot`). Канал — `DOCS_CHANNEL` в `.env`.
- Короткая справка прямо в боте: `/help голод`, `/help дуэли`; кнопка «Подробнее» ведёт на пост.

✅ **0.3. Обновление — само при запуске бота.** Бот сверяет файлы с тем, что уже опубликовано,
и **правит** изменившиеся посты, а не шлёт новые: ссылки не ломаются, канал не засоряется.

## Части

✅ **A. Формат и публикация в канал.**
- Файл — раздел — пост. Порядок — по имени файла (`01-…`, `02-…`). Шапка:
  ```markdown
  ---
  title: Голод
  help: голод, голодание, жертвы
  ---
  ```
  `title` — название в оглавлении, `help` — слова для `/help <тема>`.
- Пост-оглавление со ссылками на разделы, закреплён в канале.
- Что где опубликовано — таблица `docs_posts` (раздел, id сообщения, хеш текста). Удалённый
  файл — пост удаляется.

🔲 **B. `/help <тема>` в боте.** Короткую версию раздела делает нейросеть один раз при
изменении файла и кладёт в базу; блок `кратко:` в шапке файла заменяет нейросеть. Детали —
когда дойдём.

🔲 **C. Тексты разделов.** Черновики по коду пишет Claude, владелец правит.

🔲 **D. Документация не отстаёт от кода.** Тест в CI сверяет команды в роутерах с
`docs/players/`; справка для огрызаний (`services/roast/prompts/commands.md`) собирается из тех
же файлов.
