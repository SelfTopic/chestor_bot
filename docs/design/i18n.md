# Перевод бота на другие языки — план

Живой документ, как остальные в `docs/design/`. Главные правила решены (часть 0), детали
каждой части решаются, когда до неё доходит работа.

Зачем: больше половины подписчиков каналов с эдитами (те, что ищут «1000-7») — из Ирана и
других стран Ближнего Востока. Статистика языков каналов показывает персидский, арабский,
турецкий и английский. Похожих ботов там почти нет, а теряем этих игроков мы только из-за
языка.

## Как читать

- ✅ **решено** — договорились, можно делать.
- 🔲 **открыто** — нужно решение владельца, без него не начинать.
- 💡 **идея** — можно сделать, решить, нужно ли вообще.

## Часть 0 — правила

✅ **0.1. Языки.** Первым идёт английский. Его поймут и иранцы, и арабы, поэтому с ним
бота уже можно показывать всей новой аудитории. После него — персидский (фарси) и арабский,
когда найдутся носители, которые вычитают перевод.

💡 **0.1.1. Турецкий** есть в статистике каналов, но пока отложен.

✅ **0.2. Основа — русский.** Дерево `Dialogs` по-прежнему строится по русским YAML.
Переводы лежат рядом, с теми же ключами и подстановками. Перевод, в котором подстановки не
сходятся с русской фразой, не загружается — та же проверка, что сейчас для YAML и дерева.

✅ **0.3. Мир один.** Топы, экономика, семьи и история боёв общие для всех языков. Язык
меняет только то, как бот говорит, а не правила игры.

✅ **0.4. У иностранцев свои чаты.** Русские и иностранные игроки в одном чате не
смешиваются, поэтому язык группы задаёт чат, а не каждый игрок по отдельности.

✅ **0.5. В личке язык выбирает игрок.** По умолчанию берётся язык его Telegram.

✅ **0.6. Если фразы нет в переводе, бот отвечает по-английски, а если нет и
английской — по-русски.** Так язык можно выпускать частями, не дожидаясь перевода всех
фраз. Иранцу английский понятнее русского.

✅ **0.7. Голос бота тот же на всех языках:** грубо, со сленгом. Черновик перевода пишет
Claude, а фарси и арабский вычитывает носитель. Английский можно выпускать и без
вычитки.

✅ **0.8. Порядок этапов.** Каждый этап выкатывается отдельно:
1. Механизм языка: язык чата и игрока, выбор фразы, проверка переводов. Работает только
   русский, для игроков ничего не меняется.
2. Английский: фразы, слова-команды, игровой словарь, документация игроков.
3. Персидский и арабский: перевод, вычитка носителем, проверка письма справа налево вживую.

## Части

✅ **A. Язык чата.**
- ✅ В новом чате бот говорит на языке Telegram того, кто его добавил. Если такого языка у
  бота нет, бот говорит по-английски.
- ✅ Приветствие при добавлении в чат (`BotAddedHandler`) всегда заканчивается строкой на
  английском вроде `Choose language: /lang`. Она одна и та же на любом языке чата, поэтому
  её поймут, даже если бот выбрал язык неправильно.
- ✅ Язык группы через `/lang` меняют только админы Telegram. Обычному игроку бот отвечает,
  что команда только для админов.
- ✅ `/lang` показывает кнопки языков, каждая подписана на своём языке: 🇬🇧 English,
  🇷🇺 Русский, позже 🇮🇷 فارسی и 🇸🇦 العربية.

✅ **B. Язык в личке.** Та же команда `/lang` с теми же кнопками. Язык выбирает сам игрок,
и меняется он только в его личке. По умолчанию — язык Telegram игрока.

✅ **C. Слова-команды.** Около сотни триггеров на русском («распрофиль», «бот выбери»,
«песня», …). Нужны свои слова на каждом языке.
- ✅ Любой чат понимает команды на всех языках, язык чата влияет только на ответы.
  Английские слова подбираются так, чтобы не срабатывать в обычном разговоре.
- ✅ Пробела в selfrot нет: слова на разных языках — `Text(...) | Text(...)`, команды с
  аргументами — `AnyCommand`. Английские слова лежат в коде рядом с русскими.
- ✅ Английские слова:
  - профиль → `profile`, распрофиль → `race profile`, бал → `bal`;
  - растить кагуне → `grow kagune`, кагуне → `kagune`, щелк → `snap`, пить кофе → `drink coffee`,
    сожрать человека → `eat human`, качаться → `train`, голод → `hunger`, реген → `regen`,
    боевая мощь / бм → `combat power` / `cp`, эволюция / мутация → `evolution` / `mutation`,
    бить моба → `fight mob`, дуэль → `duel`, промо → `promo`, квиз / викторина → `quiz`;
  - топ бал / щелк / бм / кагуне → `top bal` / `top snap` / `top cp` / `top kagune`;
  - перевести / кинуть / подать → `send` / `pay`; депнуть → `bet` («депнуть» — сленг русских
    казино-стримов, англоязычный игрок его не поймёт), цвета `red`, `blue`, `green`, `white`, `yellow`;
  - брак / свадьба → `marry` / `wedding`, семья → `family`, браки → `families`, развод → `divorce`,
    имя семьи → `family name`;
  - бот → `bot`, бот выбери / кто / число → `bot pick` / `bot who` / `bot number`, песня → `song`,
    шазам → `shazam`, правила → `rules`;
  - мут / размут / бан / разбан / кик → `mute` / `unmute` / `ban` / `unban` / `kick`, варн → `warn`,
    снять варн → `unwarn`, варны → `warns`, настройки модерации → `moderation settings`,
    новые правила / приветствие / прощание → `new rules` / `new welcome` / `new goodbye`.
- ✅ Английские слова и английская справка делаются вместе: `test_player_docs.py` сверяет
  каждый триггер с заголовками справки.

✅ **D. Игровой словарь в коде.** Решения владельца не нужны, это работа в коде. Типы кагуне, статы, цвета лотереи и подписи в
rich-сообщениях сейчас лежат в коде. Их нужно перевести так, чтобы данные в БД остались
прежними.

✅ **E. Документация игроков.** У каждого языка свой канал с теми же разделами: бот сам
публикует посты и держит оглавление, как в русском. `/help` отвечает разделами на языке
чата. Канал создаёт владелец.

✅ **F. Нейросеть.** Огрызания и «бот найди» работают только там, где язык русский. В
остальных чатах и личках бот на них молчит. Их включат, когда хватит сил, денег и
времени на нормальный RAG на всех языках.

✅ **G. Аниме.** `/anime` режет серии с русской озвучкой, поэтому работает только там, где
язык русский. Серии на других языках владелец найдёт позже, и юзербот будет качать их так
же, как русские. «1000-7» обходится без слов и работает везде.

✅ **G.1. Wordle** загадывает русские слова и принимает только русские буквы, поэтому тоже
работает только там, где язык русский. Английский Wordle (словарь, буквы, склонение
«попыток») — отдельная работа, если игроки попросят.

✅ **G.2. «Цитата»** берёт русские цитаты с citaty.info, поэтому тоже работает только там,
где язык русский. В остальных чатах бот не молчит, а отвечает фразой вроде «на вашем языке
цитат пока нет, скоро завезут».

✅ **G.3. `/anime` и Wordle** в нерусских чатах тоже отвечают фразой «на вашем языке пока нет,
скоро будет», а не молчат: иначе команда из справки выглядит сломанной. Фраза уходит на языке
чата, как любой ответ, поэтому у неё обязателен английский перевод. Молчат только огрызания и
поиск: это не команды, а реакция на обычные сообщения.

✅ **H. Числа.** `format_amount` разделяет тысячи запятой во всех языках, в русском тоже
(`1,000,000`), вместо нынешней точки.
