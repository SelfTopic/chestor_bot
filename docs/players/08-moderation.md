# 🛡 Модерация чата

Бот модерирует чат вместо отдельных ботов-модераторов. Командами пользуются **админы чата**,
и бот проверяет их права в Telegram: мутить, банить и выдавать варны может тот, у кого есть
право «Блокировка пользователей».

## Наказания

Кого — **реплаем** на сообщение или **@username** где угодно в тексте. Срок и причина —
по желанию.

| Команда | Пример |
|:--|:--|
| мут / размут | `мут 30м флуд`, `мут @username 1 час спам` |
| бан / разбан | `бан 1д реклама`, `бан навсегда` |
| кик | `кик флуд` |
| варн / пред, снять варн | `варн оффтоп` |
| варны (/warns) | свои предупреждения видит любой, чужие — админ |

Без срока — срок по умолчанию (30 минут, меняется). **навсегда** — без срока.
Бот сам объявит в чате, когда мут закончится.

## Варны

Набрал лимит варнов — получил наказание. По умолчанию: **3 варна → мут на 30 минут**,
варны сгорают через **7 дней**. Всё это настраивается.

## Настройки

**настройки модерации** (/moderation) — меню-таблица с кнопками: включить и выключить
функции, сроки, лимит и наказание за варны, стиль ответов. Менять — с правом
«Изменение профиля группы».

| Команда | Что настраивает |
|:--|:--|
| мут дефолт, бан дефолт | срок без указания срока |
| варн лимит, варн наказание, варн срок | сколько варнов, какое наказание, когда сгорают |
| стиль модерации грубый / нейтральный | как бот разговаривает |
| чат админов (/set_admin_chat) | куда бот пишет журнал наказаний — настраивает владелец чата |
| новое приветствие, новое прощание, новые правила | тексты для новичков, ушедших и команды **правила** |
