# 🤗 RP commands

### rp commands

An RP command is an action on another player: write it as a **reply** to their message or with
a **@username**, and the bot tells what you did: "Ali patted Sam on the head".

Each chat has its own set of commands: the members create them.

### /all_rp

All RP commands of this chat.

### /set_rp

Add your own: the command on the first line after `/set_rp`, the action on the second.

```
/set_rp
pat
patted on the head
```

**With a GIF or a picture:** send it with a one-line caption,
`/set_rp pat patted on the head` (the first word after `/set_rp` is the command, the rest is the
action). Then it comes along with the action.

A chat has a limit of RP commands.

### /del_rp

Delete an RP command: `/del_rp pat`.
