# 🤗 RP-команды

RP-команда — действие над другим игроком: напиши её **реплаем** на его сообщение или с
**@username**, и бот расскажет, что ты сделал. Свой набор у каждого чата: команды
заводят сами участники.

- **/all_rp** — все RP-команды этого чата;
- **/set_rp**, а на следующих строках команда и действие — добавить свою:
  ```
  /set_rp
  погладить
  погладил(-а) по головке
  ```
- **/del_rp <команда>** — удалить свою.
