# 🤗 RP-команды

### rp-команды

RP-команда — действие над другим игроком: напиши её **реплаем** на его сообщение или с
**@username** — бот расскажет, что ты сделал: «Вася погладил(-а) по головке Петю».

Набор команд свой у каждого чата: их заводят сами участники.

### /all_rp

Все RP-команды этого чата.

### /set_rp

Добавить свою: команда на первой строке после `/set_rp`, действие — на второй.

```
/set_rp
погладить
погладил(-а) по головке
```

**С гифкой или картинкой:** отправь её с подписью в одну строку —
`/set_rp погладить погладил(-а) по головке` (первое слово после `/set_rp` — команда, остальное —
действие). Тогда она будет приходить вместе с действием.

У чата есть лимит RP-команд.

### /del_rp

Удалить RP-команду: `/del_rp погладить`.
