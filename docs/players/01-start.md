# 👋 Как начать

CheStor — бот по «Токийскому гулю» и заодно помощник чата: игра, модерация, видео
и музыка по ссылкам. Команды пишутся **обычным текстом без слэша**, если не сказано иначе.

## Первые шаги

1. **растить кагуне** — стать гулем. Дальше эта же команда растит кагуне.
2. **щелк** — ломать пальцы раз в 10 минут и получать CheSton.
3. **профиль** и **распрофиль** — посмотреть себя и своего гуля.

## Деньги

| Команда | Что делает |
|:--|:--|
| **бал** | твой баланс CheSton |
| **топ бал** | самые богатые |
| **кинуть 500** реплаем | перевести деньги, с подтверждением кнопками |
| **кинуть @username 500** | то же, по имени |

<details><summary>Как ещё заработать</summary>

- **пить кофе** — раз в 30 минут, открывается после 100 щелчков, даёт больше денег
- **вордли** — угадать слово из 5 букв
- **/quiz** — вопрос по лору «Токийского гуля»
- **бить моба** — награда за победу

</details>
