# 🎲 Игры и развлечения

## Игры с наградой

- **вордли** (или /wordle) — угадать слово из 5 букв, награда за победу
- **/quiz** — вопрос по лору «Токийского гуля»
- **депнуть красный 500** — лотерея: цвет и ставка

## Просто повеселиться

| Команда | Пример |
|:--|:--|
| бот выбери | `бот выбери пицца или суши` |
| бот кто | `бот кто сегодня гуль` |
| бот случайный участник | — |
| бот число | `бот число 1 100` |
| пример | `2+2*3` — бот посчитает |
| бот найди | `бот найди что такое кагуне` — ответ из интернета |
| 1000-7 | случайный эдит по «Токийскому гулю» |
